# dns-net v0.1.0 - Scaffold

**The repository and the plan.** v0.1.0 sets up the crate in the portfolio template and writes down the design before any code. There is no functional code in this release.

## What is dns-net?

<strong>dns-net</strong> turns names into addresses without the blocking resolver of the operating system. The message codec is sans-IO and strict; the resolver adds caching, retries, and transport over net-io.

## What's in 0.1.0

- The crate manifest: edition 2024, MSRV 1.85, no dependencies, `Apache-2.0 OR MIT`.
- CI on Linux, macOS, and Windows, on stable and 1.85, plus `cargo audit` and `cargo deny`.
- `dev/PLAN.md`: purpose, scope, architecture, threats, ecosystem, open decisions, and the decision log.
- `dev/DIRECTIVES.md` (engineering law and definition of done) and `dev/ROADMAP.md` (phases with exit criteria).
